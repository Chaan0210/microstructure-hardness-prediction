- **Public 9.0381(053) → 8.9963(057) → 8.9831(061)**, 처음으로 9.0 미만. 3위 유지, 4위(9.066)와의 격차 0.03 → 0.08. 최종 자동 선택(Public 최고)은 061.

## 4. 병목 진단(새 방법: 측정 정보 감사)
- **같은 행·같은 라벨에서 측정만 교체**: 깨끗한 train 249장의 보정 열화본을 운영 파이프라인에 통과시켜 TabPFN CV 비교.
  깨끗 8.93 / deg 10.76 / deg2 12.00 / deg3 13.95, 실제 잡음 절반 단독 12.23 → 잡음 행 초과 오차의 대부분은 측정 정보 손실.
- 특징군 교체(deg2): 구역(64px) 크기 불균일(het)만 열화 10.87 / 만 복원 10.54, 2상 9.65 / 11.35 → het > 2상 > 크기.
  오차 절반 복구: het 11.12, het+2상 10.47. 학습 곡선: deg2 12.22(100장) → 11.58(200장) → 잡음 영역은 데이터 제한.
- 깨끗한 행: err² ≈ 46 + 3760/N(결정립 수), R²는 N과 무관하게 ≈0.77 → 결정립 단위 무작위성 바닥. 개선 여지 거의 없음.

## 5. 새 방법: 열화 전이 증강(degradation-transfer augmentation)
- 라벨 보존 열화본(train 이미지 증강, 열화 매개변수는 우리 train 통계로 보정)을 RidgeCV/logRidge 학습 행에 추가(검증 겹 원본의 열화본은 제외).
  증강 logRidge 단독 잡음 행 RMSE 11.93 — 053 혼합(12.58)과 TabPFN 블록(12.59)보다 좋은 최강 잡음 행 예측기.
- 대조: 라벨을 섞은 열화본 −0.29, 무증강 대조 0, dev와 무관한 train 100행(잡음 35행) 11.80 → 10.77.
- TabPFN은 열화본을 문맥에 넣어도(전체/잡음 전용/잡음 범위 일치) 개선 없음 또는 악화 → 이득은 전역 감쇠 관계를 배우는 선형 모형에 특이적.
- Public: **057(같은 비중 교체) 8.9963**, 059(증강 짝 비중 0.77) 9.0592, 060(절반) 9.0053. 비중 확대는 train 잡음 행의 꼬리(극단값)에 과적합.
- 열화본 확대: deg4(보정 프리셋 기본값, train 잡음 ≥12 풀)를 새로 만들고 잡음 ≥12 열화본 전부(약 730행)로 학습 → dev 9.6636(+0.103), **061 Public 8.9831**.
  독립 holdout 잡음 35행 11.80 → 10.79. gmm 짝 증강·중간 구간(9.5~12) 증강은 불안정/악화로 제외.

## 9. dev ↔ Public 관계 재분석과 다음 연구 (10-14 밤)
- dev 자체도 선택 편향: 변형 95개 등록부의 반분 재현에서 400행 dev 차이의 신뢰도 ≈ 0.6(1등 변형은 효과의 0.55~0.73만 재현).

# 타깃 층화·분할 안정성 읽기 진단

**판정: 현재 분할을 교체하거나 새 분할 실험을 시작할 필요성은 입증되지 않았다. 향후 승인된 새 비교에서 타깃 분포 균형을 높이려는 목적으로 한 번 고정한 group 보존 층화 정책은 합리적이다. 현재 실패 모델을 구제하거나 선택 편향을 없애는 방법으로 사용해서는 안 된다.**

세 분할은 같은400개 ID·라벨·group을 사용한다. 전체 타깃 분포가 정확히 같으므로 전체 OOF RMSE 12.6219–13.0324의 차이는 평가 표본의 타깃 구성비만으로 설명되지 않는다. 분할에 따른 학습집합·내부선택·fold별 seed/모델 변화가 개별 예측을 바꾸는 문제와, fold별80장 구성 차이를 구별해야 한다.

## 기존 진단과 이번 추가분

- docs/records/roadmap-audit/roadmap-30-after-215.md:48은 GroupKFold 반복은 완료, 타깃 층화는 미실시라고 명시한다. GroupKFold에 y를 넘겨도 층화가 되지 않는다.
- mean-only-control/target-balance-readonly.json은 fold별 타깃 mean/std/quintile 빈도까지만 계산했다. 이번 계산은 그 수치를 exact 재현하고, 꼬리10% 빈도·train/validation 분포 차이·best021 OOF 오차와의 연결·사후 구성 표준화·동일ID 오차 분해를 추가했다.
- 160은 생성 family를 확정하지 못해 임의 approximate group 생성을 기각했다. exact/D4 group400개가 각각 고유하다는 사실은 실제 독립 생성자료400개를 증명하지 않는다.
- 166/167 및 L3는 반복400 재사용, 큰 오차 집중, 타깃 꼬리 잔차 해석 한계를 이미 기록했다. 이번에는 새로운 high-error ID 군이나 제외 규칙을 만들지 않았다.

## 자료 일치와 타깃 분포

개발400의 전체 hardness 평균 194.076758, 모집단 표준편차 18.034521, 분산 325.243933, 범위 [151.979828, 264.121303]. 세 OOF의 ids/y/g는 원소별 정확히 일치한다. 각 분할은 train320/validation80×5이며 group이 train/validation에 걸치지 않는다.

전체 개발 라벨의 하위10% 경계 170.803080, 상위10% 경계 217.135515; 각 꼬리40장, 중간320장. 아래 구간 정의는 사후 설명용이며 모델 입력·전처리·선택에 사용하지 않았다.

## OOF 오차와의 관계

| 분할 | 하위10% RMSE | 중간80% RMSE | 상위10% RMSE | 양쪽10% 합계의 SSE 비중 |
|---|---:|---:|---:|---:|
| original | 19.903 | 9.787 | 21.734 | 53.13% |
| 20261031 | 19.468 | 9.688 | 21.524 | 52.87% |
| 20261101 | 20.745 | 9.862 | 22.136 | 54.19% |

꼬리80장(20%)이 SSE의 약53–54%를 차지한다. 낮은 타깃은 과대예측, 높은 타깃은 과소예측하는 방향이 세 분할에 공통이다. 이는 이미 알려진 tail difficulty의 정량 연결이며, 라벨 오류·물리적 잡음 바닥·특정 보정법 성공을 입증하지 않는다. 실제 target 분위는 추론 시 알 수 없으므로 target bin별 보정/가중을 제안하지 않는다.

15개 fold는 같은400장을 공유하므로 독립 관측15개가 아니다. 유의성 검정·p-value·독립표본 CI를 만들지 않았다. 아래는 기술적 Pearson 상관이다.

| fold별 요약 대 fold MSE | 15fold 상관 | 각 분할 mean을 뺀 상관 |
|---|---:|---:|
| target mean | -0.220 | -0.230 |
| target std | +0.458 | +0.473 |
| 하위10% 표본 수 | +0.003 | +0.003 |
| 상위10% 표본 수 | +0.198 | +0.207 |
| 양쪽10% 총 표본 수 | +0.152 | +0.158 |
| target quintile 구성만의 예상 MSE | +0.241 | +0.252 |
| 다른 두 분할의 같은ID 평균SE | +0.798 | +0.877 |

꼬리 개수만으로 fold MSE를 잘 설명하지 못한다(총 개수 상관 약0.15). 타깃 표준편차와의 상관은 약0.46으로 일부 관계가 있지만 인과 원인으로 분해한 값이 아니다. 같은ID의 다른 분할 오차 구성과의 상관은 약0.80으로 더 크다. 이는 bin 안에서도 샘플별 난도가 다르다는 설명과 맞지만, 다른 두 OOF 역시 학습자료를 겹쳐 쓰므로 독립 예측력 검증이 아니다.

### 같은 타깃 구성으로 사후 표준화하면 fold 변동이 사라지는가

각 fold의 quintile별 MSE를 같은20% 비중으로 평균했다. 같은 기존 예측을 요약하는 계산뿐이며, 원래 공식 점수나 승격 판정을 바꾸지 않는다. 모든fold의 모든bin에 표본이 있어 빈bin 대입은 없다.

| 분할 | 원래 fold MSE의 표준편차 | 균등 quintile 요약 후 | 변화 |
|---|---:|---:|---:|
| original | 15.482 | 14.481 | -6.47% |
| 20261031 | 15.261 | 18.788 | +23.11% |
| 20261101 | 11.791 | 8.898 | -24.53% |

원본은6.47% 감소, 20261101은24.53% 감소했으나 20261031은23.11% 증가했다. **이 사후 표준화는 모델을 새 층화 분할에서 다시 학습한 효과가 아니다.** 관측된 fold 변동을 단순 target 구성 하나로 정리할 수 없다는 진단으로만 사용한다.

### 전체 분할 간 차이는 같은ID의 예측 변화

| 비교(두 번째−첫 번째) | 전체 MSE 차이 | 예측 RMS 차이 | signed residual 상관 |
|---|---:|---:|---:|
| 20261031 − original | -4.174510 | 2.9989 | 0.9723 |
| 20261101 − original | +6.357802 | 3.1195 | 0.9712 |
| 20261101 − 20261031 | +10.532312 | 3.4071 | 0.9653 |

20261031→20261101의 MSE 악화 10.532312 중 낮은20%와 높은20%(합계160장,40%)의 순변화 기여가 98.39%다. 이 비교는 동일ID·동일target bin 구성에 대한 오차 변화다. ‘나쁜 분할에 꼬리 이미지가 더 많이 들어왔다’로 설명할 수 없다. 세 분할 전체에는 항상 각 bin80장이 있다. 특히 OOF signed residual 상관이0.965–0.972로 높아 반복분할이 새로운 독립 검증 역할을 하지 않는다.

정확한 산술 분해도 저장했다: ID별3분할 평균SE를 d_i라 하면 각 fold MSE는 fold 안의 평균d_i + 해당 분할 SE−d_i 평균이다. d_i는 현재 분할 자체도 포함하는 사후 설명값이므로 독립 난도 추정이나 분산 설명률로 주장하지 않는다. 직접 자기포함을 줄인 다른2분할 meanSE 상관을 위에 따로 보고했다.

## 향후 층화 정책이 필요한가

현재 기록만으로 기존 세 분할을 폐기·교체하거나 best021/기각모델을 새 seed에서 재평가할 필요는 없다. **층화는 선택적 프로토콜 개선이며 현재 성능 문제의 입증된 해결책이 아니다.**

향후 원래 계획에 없던 독립 가설의 비교가 별도로 승인된다면, 모델 결과를 보기 전에 고정하는 outer5fold의 group 보존 target decile 층화가 합리적인 선택이다. 지금400개의 exact/D4 group은 모두 singleton이고 각 decile40장이므로, 수학적으로 각 fold에 각 decile8장(전체80장)을 균등 배정할 수 있다. 이 진단에서는 실제 ID 배정·seed 선택·새 split 파일을 만들지 않았다.

정당한 목적은 fold별 target tail 지원을 균등화하고 같은 train size의 비교 정밀도를 높이는 것이다. 단일 seed를 사전 기록하고 후보와 best021에 같은 분할을 적용해야 한다. 여러 seed 중 좋은 점수의 분할을 고르면 안 된다. split 생성을 위해 개발 y를 사용하는 것은 명시적 층화 설계이지만, 이후 모델 전처리·타깃 통계·inner tuning은 각 training subset 안에서만 fit해야 한다. inner CV도 사전 고정한 train-local binning 규칙을 적용해야 하고 outer validation 라벨로 내부 경계를 정하면 안 된다.

새 split에 기존 OOF 배열을 재배열하는 것은 재검증이 아니다. 새로운 outer fold의 완전한 학습범위로 모든 선택·보정·잔차 단계를 다시 구성해야 하므로, 승인 없는 학습으로 이어가지 않는다. 정확/D4 group이 미래에 여러 행을 포함하게 되면 group 분리를 우선하며 완벽한 분위 균등보다 데이터 관계를 보존해야 한다. 확인되지 않은 생성 family를 임의로 만들어 group화하지 않는다.

## 선택 편향과 실행 한계

- 이미 수백 번 사용한 개발400의 역사적 모델/feature/가설 선택 편향은 층화·새 seed·반복 CV로 제거되지 않는다.
- fold별 분포를 균등화하면 관측 fold 변동이 작아질 수 있으나 독립 데이터나 작은 일반화 불확실성을 의미하지 않는다. 오히려 일부 분포 차이를 설계로 억제한 것이다.
- 현재 target tail/signed error·bin별효과는 사후 진단이다. 이를 보고 target-specific 모델·표본제외·비중 최적화를 이번 작업에서 만들지 않았다.
- 기존 fold별 seed offset(예: experiments/01-representations/0177-dinol/readout.py:42) 때문에 split 변경은 training membership 외에 각 ID에 적용되는 seed/model도 바꿀 수 있다. 본 진단은 이 효과들을 분리한 인과 실험이 아니다.
- 유일한 그룹400개는 정확/D4 중복 기준이다. 실제 생성 family 독립성은 160의 한계대로 미확정이다.

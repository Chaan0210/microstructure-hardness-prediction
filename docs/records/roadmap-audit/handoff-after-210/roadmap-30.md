# 210 이후 로드맵 30개 항목 관리표

상태 합계: **완료 18개 · 부분 9개 · 미실시 3개**. 원본 [204 이후 감사](../audit.md)를 보존하고 205–210을 반영했다.

완료는 명시한 범위의 구현·대조·진단을 수행했다는 뜻이다. 기법의 모든 설정을 소진하거나 문제를 해결했다는 뜻이 아니다. 미실시는 검토한 기록에서 실행 근거가 없다는 뜻이다. 수치는 별도 표시가 없으면 개발 OOF RMSE이며 개선은 대조−후보다. CI는 저장된 결과에 조건부인 95% 구간이다.

## 다음 세션의 잔여 검토: 최대 두 개

1. **현재 TinyCNN의 MSE–Huber 단일 변경 대조가 실제로 누락됐는지 확인하고 설계 가능성을 검토한다.** 058은 동결 DINO head, 185–190/210은 다른 사전학습 CNN이다. 현재 TinyCNN과 같은 입력·분할·seed·update·평균 경로의 손실 대조는 확인되지 않았다. 구조·데이터·증강 확대 없이 구분 가능한 질문이다. 정확히 같은 대조 기록이 있으면 건너뛴다. 큰 오차를 라벨 오류로 전제하지 않고 Huber 임계값·목적을 사전에 설명할 수 없으면 보류한다. 다음 세션의 기록 확인과 단일 정책 설계 검토만 추천한다. 실행 승인·실험 번호 부여·계수 탐색·후단 재학습은 포함하지 않는다.

2. **물리 측정의 정답·길이 스케일 또는 검증 가능한 생성 과정 자료의 확보 가능성을 확인한다.** 097/098/183의 병목은 물리 측정의 안정성·충실도다. 205의 전이학습과 206의 순위·gradient 검사는 이를 해결하지 않았다. 정확한 측정 없이 회귀기만 바꾸면 측정 실패와 학습 실패를 분리할 수 없다. 새로운 허용된 결정립/상 정답, 물리적 픽셀 길이 또는 생성 과정 근거가 없으면 종료된 segmentation·평활화·역렌더링을 반복하지 않는다. 확보 가능한 근거가 있는지 검토하는 단계다. 근거가 생기면 먼저 측정 정확성과 안정성을 별도로 정의한다. 외부 자료 검증은 별도 연구 범위이며 이 인계에서 외부 호출·다운로드·학습을 하지 않는다.

미실시 항목을 실행 대기열로 만들지 않는다. 밝기·감마·blur·noise의 추가 적용에는 라벨 불변성 근거가 필요하다. 기존 분할은 같은 400장을 반복 사용한 것이며 새 분할도 독립 holdout이 아니다. 고정 256→224 resize와 무작위 scale 증강은 다르다. D4 결과로 타깃 방향 의존성을 증명할 수 없고, 리더보드만으로 잡음 바닥을 확정할 수 없다. 0 예측 RMSE는 sqrt(mean(y²))이며 타깃 평균이 아니다.

## 전달받은 공식 연구 결과의 반영

아래 내용은 상위 세션의 별도 공식 자료 조사 결과를 전달받아 반영했습니다. 이 로컬 작업에서 웹을 재조회하거나 자료·가중치를 내려받지는 않았습니다.

- [대회 공식 설명 PDF](https://cfiles.dacon.co.kr/competitions/daker_9monthly/%E1%84%86%E1%85%B5%E1%84%89%E1%85%A6%E1%84%80%E1%85%AE%E1%84%8C%E1%85%A9_%E1%84%89%E1%85%A5%E1%86%AF%E1%84%86%E1%85%A7%E1%86%BC.pdf)는 물리적 길이 스케일을 제공하지 않습니다. 기공·불균일성이 경도를 낮춘다고 단정하지 않고, 절대 방향과 정렬 정도를 구분합니다. 따라서 로드맵의 물리적 부호를 정답 생성식으로 가정하지 않습니다. 이는 기존 111·097·183의 측정 한계와도 일치합니다.
- NASA 공식 README와 특정 [MicroNet ResNet50 카드](https://huggingface.co/jstuckner/microscopy-resnet50-micronet)에는 pretrained encoder/해당 가중치의 MIT가 확인됐다는 전달을 받았습니다. 실제 파일은 `resnet50_micronet_weights.pth`, 표시 크기 약 94.3 MB, SHA256 `4c906df94c224efa267e59311244900a5633549aeda5e11f5ecfade6f30bafd2`입니다. 카드 본문의 `encoder_weights.pth`와 실제 파일명은 다릅니다. 로컬 다운로드·해시 실측·strict load는 아직 하지 않았습니다.
- 공식 encoder는 SMP ResNet50, RGB [0,1], ImageNet mean/std, 256 입력을 사용한다는 전달입니다. 원 환경 torch 1.10.1 / torchvision 0.11.2 / SMP 0.2.1 / timm 0.4.12와 현재 환경이 다르며, HF 파일의 v1.0/v1.1 대응도 불명확합니다. 동명 ResNet50이라는 이유만으로 구조·state 호환을 가정하지 않습니다.
- [MicroNet 원논문](https://www.nature.com/articles/s41524-022-00878-5)의 이득은 segmentation입니다. 합성 경도 회귀 개선이나 DINO 대비 우월성을 입증하지 않습니다. [2024 회귀 연구](https://arxiv.org/html/2410.20402v1)는 Gd 조성·결정립·2상 관련 4개 수치, 학습 19그룹/시험 2그룹을 사용하므로 영상만 입력하는 이번 과제와 다릅니다. [2017 VGG 연구](https://arxiv.org/pdf/1711.00404)는 다층 특징을 사용한 분류 연구이며 경도 회귀 실험이 아닙니다.
- Pawpularity 원저자의 동결 특징 SVR와 별도 영상 회귀 ensemble은 전달된 조사에서 확인됐지만, 보조 타깃이 핵심 기법이라는 주장은 확보 원문으로 확인되지 않았습니다. 로컬 `ID,hardness`에는 독립 보조 타깃도 없으므로 이를 근거로 종료된 CE 분기를 재개하지 않습니다.

## 판단과 다음 한 개

- 다음 한 개는 [205 제안: 동결 ImageNet ResNet50 대 MicroNet ResNet50](next-experiment-205.md)입니다. 동일 구조·입력·pooling·회귀 복잡도에서 사전학습 가중치 출처만 비교합니다. 기존 ImageNet 가중치와 native256 특징을 대조로 활용하며, fine-tuning·D4·다층 특징·EMA·추가 구조는 넣지 않습니다. MicroNet의 경도 회귀 이득이 입증됐다는 뜻은 아닙니다.
- 049·098·183은 **물리 측정의 안정성·충실도 관문에서 멈춘 사례**입니다. 학습한 회귀기가 실패한 사례로 기록하지 않습니다. 반대로 027·058·190의 OOF 악화만으로 입력 측정이 물리적으로 틀렸다고 판단하지 않습니다.
- 0 예측의 RMSE는 `sqrt(mean(y²))`이며 타깃 평균이 아닙니다. 평균 예측 기준도 각 fold의 학습 평균을 사용해야 합니다. 리더보드 점수만으로 비가역적 잡음 바닥을 확정할 수 없습니다.
- 미실시 항목을 모두 실행 대기열로 만들지 않습니다. 광도·blur·noise·scale 변환의 라벨 불변성, 신규 가중치 출처 등은 별도 근거가 필요한 질문입니다. 같은 400장의 세 분할은 1,200개 독립 표본이 아니며 조건부 bootstrap은 누적 연구 선택 편향을 보정하지 않습니다.

기존 파일을 보존했습니다. 원시 이미지·모델·OOF 배열을 새로 추론하거나 평가하지 않았고, 학습·설치·다운로드·외부 호출·holdout/test 평가·제출을 시작하지 않았습니다. 이번 로컬 작업의 추가 비용은 0입니다. 입력 근거와 해시 검증은 [검증 기록](verification.json)에 있습니다.

# 210 완료 관리표

**사전 primary 기준 미달. 이 고정 LLRD 정책을 종료하고 비율 탐색 없이 best021을 유지한다.**

| 항목 | 상태 | 결과·범위 |
|---|---|---|
| 깊이별 LR 대조 | 완료 | 기존 ConvNeXt 마지막 세 블록의 정규화 ratio 0.8 한 정책. 평균 LR·실제 decay 고정. |
| 기존 대조 재현 | 통과 | 5개 OOF·train 재로드 exact. Fold 0 그룹 분할 재학습 state·OOF·전체 trace exact. |
| 단독 OOF | 완료 | 16.7641850464 → 16.7681290522, 개선 -0.0039440058, CI [-0.01321240480664647, 0.005391779873496193], 상위 5개 제외 -0.0083899946. |
| Train/OOF 격차 | 진단 완료 | Train 3.80871478 → 3.76664483. 격차 감소 -0.04601396. Train 오차는 더 낮아졌지만 OOF는 악화했고, train/OOF 격차도 더 커졌다. 이번 고정 LLRD가 과적합 격차를 줄였다는 근거는 없다. |
| 고정 앙상블 | 완료 | Best021 대비 개선 -0.1723121648, CI [-0.2820342062686717, -0.060728247790295016]. 후보 10% 추가 blend이며 첫 seed 치환이 아님. |
| 로드맵 LLRD | 부분 완료 | 마지막 stage 내부의 한 비율 대조를 완료했다. 전체 backbone LLRD를 수행한 것은 아님. 이번 정책은 결과대로 종료·보관하며 비율 탐색 없음. |
| 후속 확대 | 미실시 | 209 EMA 보류 유지. 새 층·입력·loss·증강·nested 재학습·최종 평가 선택·제출 없음. |

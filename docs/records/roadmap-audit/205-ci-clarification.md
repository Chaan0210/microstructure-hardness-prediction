# 205 CI의 비교 대상과 결론 범위

기존 205 보고서와 결과 파일을 보존하는 보충 기록이다. 저장된 요약을 재확인했으며 재학습·재추론·bootstrap 재실행은 하지 않았다.

`P`는 best021, `A`는 ImageNet 동결 ResNet50 + mean2048 + Ridge EDF32, `B`는 MicroNet 동결 ResNet50 + 동일 특징·회귀 방식의 OOF 예측이다. `QA = 0.9P + 0.1A`, `QB = 0.9P + 0.1B`이다. **개선량 = 기준 RMSE − 후보 RMSE이며, 양수가 개선이다.**

| 비교 | 기준 RMSE | 후보 RMSE | 개선량 | 조건부 95% CI |
|---|---:|---:|---:|---:|
| MicroNet 혼합 QB 대 best021 P | 12.7862007758 | 12.8877028120 | -0.1015020362 | [-0.1924421364, -0.0098484445] |
| MicroNet 혼합 QB 대 ImageNet 혼합 QA | 12.8684641081 | 12.8877028120 | -0.0192387039 | [-0.0967774020, 0.0567014976] |
| MicroNet 단독 B 대 ImageNet 단독 A | 15.4690007984 | 15.8745010142 | -0.4055002158 | 별도 CI 미계산 |

첫 번째 구간은 **best021 대비 10% MicroNet 추가 효과**이다. MicroNet과 ImageNet의 직접 차이에 대한 CI가 아니다. 두 번째 구간은 **동일한 10% 혼합 조건에서의 대조**이고 0을 포함한다. 단독 점추정의 열세에 첫 번째 구간을 붙여 해석해서는 안 된다.

기존 계획은 400개 ID paired bootstrap 10,000회, seed 202610205였다. 이 구간은 저장된 학습 결과에 조건부이며 재학습·seed 변동과 누적 실험 선택을 반영하지 않는다. 독립 holdout 검증이나 사전학습 데이터만의 인과 효과를 뜻하지 않는다.

205는 해당 체크포인트의 동결 특징, native 256 입력, 최종층 mean2048, Ridge EDF32, 고정 10% 혼합 조건에서 사전 기준을 충족하지 못했다. 이 분기는 종료한다. **MicroNet 전체, 다른 층·미세조정 방식 또는 현미경 사전학습 전반이 무효라는 결론은 아니다.** 새 활용법 탐색을 자동으로 시작하지 않는다.

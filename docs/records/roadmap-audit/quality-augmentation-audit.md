# 화질 증강과 물리 측정 신뢰도 후속 대조

이번 작업은 기록 분석과 다음 실험 하나의 설계에 한정했다. **대비 감소만 추가하는 CNN 대조는 미실시이나, 저장된 공식 기록으로 대비와 경도 생성의 독립성을 확인할 수 없어 실행은 보류한다.** [조건부 206 계획](next-experiment-206.md)과 [205 CI 보충](205-ci-clarification.md)을 남긴다.

183의 기존 개별 JSON을 집계하면 대비 감소의 최대 상대 변화는 count 0.00992063, median area 0.01075269, area-weighted aspect 0.00671501이다. 최소 matched source-pixel fraction은 0.98942566, 최소 adjacency Jaccard는 0.94533762이다. 대비 증가에서는 각각 0.10150376 / 0.07843137 / 0.03820918, 0.87097168, 0.71860987이다. 새 분할을 수행한 것이 아니다. 두 대비 조건의 중앙값은 변화 0, 일치율 1이지만 모든 영상에서 분할이 같았던 것은 아니다.

183은 `c × (x − 0.5) + 0.5`, float 연산, clip·재양자화 없음이었다. 제안은 영상 평균을 중심으로 하므로 같은 구현이라고 부르지 않는다. 새 변환의 수학적 불변성과 CNN 입력 경로만 좁게 검사하도록 설계했으며, 기존 분할 측정 실험을 재개하지 않는다.

205는 동결 특징·Ridge의 해당 조건에서만 기각한다. 204의 CNN seed 확대 및 후단 전체 재학습은 반복하지 않는다. 같은 개발 400장과 기존 재분할은 독립 holdout이 아니며 리더보드·조건부 CI로 잡음 바닥을 확정하지 않는다.

# 조건부 206 계획: 학습 시 대비 감소 하나만 추가

**설계 완료, 실행 보류.** 이번에는 영상 변환·구조 검사·학습·다운로드를 시작하지 않았다. 하나의 조건부 대조이며 실행 예약이나 자동 승인이 아니다.

질문은 “기존 TinyCNN의 다른 조건을 고정하고 학습 영상의 대비만 약하게 낮추면 원본 추론의 회귀 오차가 줄어드는가?”이다. [중복 감사](../../../docs/records/roadmap-audit/quality-augmentation-audit.md)에서 같은 학습 대조를 찾지 못했다. 공식 변동 기록과 183은 검토 동기이며 라벨 보존의 충분조건이 아니다.

**선행 근거 조건.** 별도 공식자료 연구가 원문 문구·위치로 대비를 구조·경도와 분리된 렌더링 또는 화질 방해요인으로 해석할 합리적 근거를 제공해야 한다. “대비가 다르다”만으로는 통과하지 않는다. 생성식 전체나 엄밀한 불변성 증명까지 요구하지는 않지만 현재 018/111 기록만으로는 조건 미충족이다. 광도·상분율이 경도 생성에 직접 쓰이는 정황이 있거나 근거가 계속 불명확하면 학습 전에 종료한다. 감마·blur로 자동 전환하지 않는다.

**강도는 라벨·모델 결과를 보기 전에 한 번 고정한다.** 현재 데이터로 강도 수치를 확정한 것은 아니다. 아래 단계도 선행 근거 조건 충족 후에만 수행한다.

1. Fold별 원본 train 320장만 기존 BOX 128/255 경로로 읽는다. `Cᵢ = q95(xᵢ) − q05(xᵢ)`와 양수 C의 train Q10·Q50을 NumPy linear quantile로 계산한다. Validation 80장의 분포를 사용하지 않는다. 097의 native 256 대비 표를 128 입력 수치로 대용하지 않는다.
2. `δ = min(0.05, max(0, 1 − Q10/Q50))`. 5%는 183 감소 검사 범위를 넘지 않는 보수적 상한이며 실제 생성 분포나 최적 강도의 추정치가 아니다. Q50 = 0 또는 δ ≤ 0.001이면 의미 있는 교란이 없어 학습 전에 중단한다.
3. `Cᵢ > Q10`이면 `cᵢ = max(1 − δ, Q10/Cᵢ)`, 아니면 `cᵢ = 1`. `xᵢ′ = μᵢ + cᵢ(xᵢ − μᵢ)`를 적용한다. μᵢ는 해당 영상 평균이다. 기존 낮은 대비 꼬리를 더 낮추지 않으며 감소 대상은 train Q10 이상에 유지한다. 밝기 이동·clip·uint8 재양자화·gamma·blur·noise 없음.
4. Float 입력의 대비 변환은 fold 표준화 전에 적용한다. 두 군 모두 같은 원본 train 영상·타깃으로 표준화 통계를 계산한다. 이후 기존 D4 순서·RNG를 유지한다. 모든 fold의 통계, δ, cᵢ, 대상 수와 검사 결과를 학습·OOF 점수 계산 전에 저장·잠금한다. 결과를 본 강도 재설정이나 sweep은 없다.

양의 affine 연산은 정확한 산술에서 평균, 픽셀 순서·동률, 공간 위치·경계 방향을 보존하고 픽셀 차이·미분 진폭을 cᵢ배 한다. `[0,1]` 값은 clip 없이 내부에 남는다. 다만 절대 밝기 임계값에 따른 상 분율과 생성 경도까지 보존한다고 단정할 수 없다. 약한 경계 신호의 진폭이 줄어드는 한계도 남는다.

**구조·구현 검사.** 모델 점수 없이 모든 train 입력에서 mean 차이 ≤ 1e-6, `[0,1]` 범위, 대비 비율의 예상값 오차 ≤ 1e-6, `∇x′ = cᵢ∇x`의 절대 오차 ≤ 1e-6을 확인한다. Float64 기준과 float32 경로를 비교하고 원본 8bit 값에서 유래한 동률 및 q10/q50/q90 rank 마스크의 픽셀 일치를 검사한다. 이는 연산 검사이며 참 상 마스크 검증이 아니다. 적어도 train의 절반에서 `1 − cᵢ > 0.001`이어야 한다. 실패 시 강도·검사 기준을 완화하지 않고 원인을 보고하고 중단한다.

시각 검사는 각 train fold에서 ID hash로 미리 고른 4장, 합집합 최대 20장의 원본·변환·차이를 같은 표시 범위로 확인한다. Clip·위치 이동·얇은 경계 또는 작은 어두운 물체의 처리상 소실이 있으면 중단한다. 새로운 watershed·inverse rendering·NLM 측정 실험은 하지 않는다. 183 검사를 반복하거나 안정성을 물리 정확성으로 대체하지 않는다. 근거 조건과 검사를 모두 통과해야 별도 승인된 학습 단계가 가능하다.

**학습 검증과 판정.** 시작 전에 원래 회귀 경로와 대비 off 경로의 초기 state·한 update·RNG 동등성을 검사한다. Fresh A의 OOF를 기존 동일 seed CNN 경로와 점수 열람 전에 비교한다. Train/validation ID·그룹 분리, train 전용 통계, validation 타깃 poison 독립성, 최종 state 재로드 예측 일치를 확인한다. 통제 재현 실패 시 후보 결과를 해석하지 않는다.

주 지표는 `RMSE(A 원본 OOF) − RMSE(B 원본 OOF)`이다. Fold별 개선, 400 ID paired bootstrap 10,000회(seed 202610206)의 조건부 95% CI, 순 제곱오차 이득 상위 5개 ID 제외 개선을 보고한다. 추가 검토 자격은 pooled 개선 ≥ 0.02, 3/5 fold 이상 개선, CI 하한 > 0, 상위 5개 제외 개선 > 0, 기술 검증 통과로 고정한다. 이는 자원 배분 규칙이지 누적 선택 편향이 보정된 유의성 검정이 아니다. 실패하면 해당 고정 대비 감소 분기를 종료한다.

성공해도 단일 seed·동일 400장 결과를 보고한 뒤 정지한다. Best021의 기존 보정·잔차에 CNN 예측을 임의 대입하여 새 성능을 주장하지 않는다. 재분할·다중 seed·후단 재학습·OOF ensemble·전체 500장 학습·test·CSV·제출은 범위 밖이다. 204 재시도나 최종 평가 선택으로 자동 연결하지 않는다.

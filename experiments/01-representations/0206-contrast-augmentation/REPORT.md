# 206: 학습 시 대비 감소 단일 대조

**사전 기준 미달. 이 고정 대비 감소 분기를 종료하고 best021 유지.** 추가 검토 기준 충족 여부는 `False`이다. 조건에 관계없이 원본 5fold 결과를 보고하고 정지하며 새 모델·제출을 선택하지 않는다.

## 시작 조건과 실제 수행

기존 206 설계의 추가 공식 원문 확인 전 보류 조건은 사용자의 새 지시로 해제했다. 대비 변동의 공식 기록, 영상 구조 보존 검사, train 전용 대조를 근거로 **타깃 불변성을 미검증 가정으로 둔 제한적 검증**을 허용한 것이다. 기존 보고서를 수정하지 않고 `authorization.json`과 새 `plan.json`에 변경 근거를 보존했다.

원본 개발 400장의 기존 5fold(320/80), seed 20261003 + fold, TinyCNN 91,905개 파라미터, 기존 BOX 128 입력, D4, MSE, train 전용 표준화, AdamW, 80 epoch/800 update, 마지막 5 epoch state 평균을 유지했다. 두 군 차이는 train 입력의 평균을 중심으로 한 양의 affine 대비 감소 하나다. 좌표·해상도 변경, clipping, 학습 입력 재양자화는 없다.

Train의 q95−q05 대비 Q10/Q50에서 사전 규칙으로 정한 감소 상한은 모든 fold에서 5%였다. 유효 감소 대상은 fold별 [276, 281, 281, 284, 285] / 320개였다. 각 ID는 고정 hash로 40회 원본·40회 변환 경로에 노출되며 c=1인 ID의 실질 변환 횟수는 0이다. 낮은 대비 영상은 train 범위를 벗어나지 않도록 감소를 제한했다. 강도와 노출 확률의 결과 기반 조정은 없었다.

## 구조 보존 및 통제 검증

- 5fold train의 총 1,600개 중복 관측에서 픽셀 순서·동률과 q10/q50/q90 rank 마스크가 정확히 일치했다. 유한차분의 부호와 0인 위치도 동일했다. 평균 오차 최대 2.58e-08, 대비 비율 오차 최대 3.56e-07, 미분 스케일 오차 최대 7.45e-08로 사전 1e-6 기준 이내였다. 값과 대비는 train 허용 범위 안에 있었다.
- 사전 선택한 19개 고유 영상의 5개 패널을 검토했다. Clip·공간 이동·처리상 경계 또는 작은 어두운 물체의 소실을 관찰하지 않았다. PNG 표시만 양자화했으며 학습에는 float 캐시를 사용했다. 참 물리 마스크·경도 보존의 증명은 아니다.
- 모든 control의 최종 state와 legacy FP32 OOF가 기존 CNN 첫 seed와 bitwise exact였다. 두 군의 초기 state, 전체 800 update의 샘플 순서·D4·LR·CPU/MPS RNG가 일치했다.
- 10개 모델의 5개 state 재평균, 재로드, train 전용 통계를 검증했다. MPS 재로드 최대 오차 0, CPU 최대 오차 3.05e-05. Validation 타깃을 NaN 또는 1e30으로 바꾼 fold0 두 군의 전체 80 epoch 재실행에서 state·예측·학습 스트림이 정확히 같았다.
- 주 학습 10회와 검증 재학습 2회. 검증을 마친 후 OOF 점수를 계산했다. 단일 seed이므로 seed 분산은 평가하지 않았다.

사전 단독 기준은 개선 ≥ 0.02, 개선 fold ≥ 3, CI 하한 > 0, 상위 5개 이득 제외 개선 > 0 및 기술 검증 통과다. 실제 판정은 `{'technical_validation': True, 'gain_at_least_0_02': False, 'at_least3_folds': False, 'conditional_CI_lower_positive': False, 'top5_removed_positive': False}`이다. 고정 앙상블과 화질 진단은 대체 후보·가중치 선택에 사용하지 않았다.

## 범위와 보존

- 같은400의 반복 사용과 누적 선택 편향. 독립 holdout 아님.
- 한 seed의 조건부 CI이며 seed분산·재학습 불확실성을 포함하지 않음.
- 구조 검사 통과와 회귀 개선 여부는 타깃 불변성 증명이 아님.
- 화질 구간은 train tertile 기반 사전 진단. 대리값의 인과 효과·라벨 오류를 뜻하지 않음.
- 실패는 이번 고정 contrast 감소 조건에 한정. 모든 증강·물리 특징의 무효가 아님.

기존 파일 59개의 SHA256을 전후 확인했다. Best021 CSV SHA256은 `7cf4ce3bbef6b98d5a06e5b3b19498379ca5fe4f076bbdc95d9afa55cc893a4b`로 유지됐다. 무료 CPU 2 threads/MPS 사용, 보수적 RSS+MPS 관측 최대 0.773 GB, swap 증가 0, 감시 단계 합계 184.4초였다. 작성 시간을 포함한 전체 벽시계 시간은 아니다.

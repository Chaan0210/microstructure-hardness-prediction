# push-1400 (10-16~): 규칙 준수 재구축 + 새 연구

## 1. 배경 — 10-16 공식 답변(사례 A/B)
- 답변 1: train 이미지를 분석한 결과(결정립 구조 등)를 바탕으로 이미지를 다시 그려 새 이미지를 만들고 학습에 쓰는 방식은 불허.
- 답변 2: train 원본에 회전·반전·크롭·밝기·대비 등 일반 변환을 적용한 학습, 그리고 train 이미지를 분석해 얻은 특징·추가 라벨을 학습에 쓰는 것은 허용.

## 2. 감사 결과(076 구성요소)
| 구성요소 | 학습 입력 이미지 | 판정 |
|---|---|---|
| U-Net u1·m1·m2·h1·m3·z1 (push-400 phase_unet*.py) | 깨끗한 train + **결정립 마스크로 결정립별 밝기 오프셋**(off[lab]) + 음영·블러·대비·잡음 | 분석 결과로 이미지를 수정 → 위험 |
| DTA 열화본 deg·deg2 (make_synth.py/2) | 결정립 마스크로 결정립별 밝기 산포 | 위험 |
| DTA 열화본 deg3·deg4 (push-900/realdeg2.py) | 마스크 기반 결정립 어두움 변경 + **경계선 화소를 결정립 평균으로 덮어 지움** | 답변 1에 해당(구조를 다시 그림) |

## 3. 준수 재구축(R/ 미러)
- `phase_unet{,2,4}.py`: off[lab] → 마스크 없는 매끄러운 무작위 밝기장(rfield, 상관 2.5~8 px). 나머지 동일. 정답(마스크 유래 라벨)은 답변 2로 허용.
- `R/`: 데이터·준수 디렉터리(push-300, grain-cellpose-220 등)는 심링크, U-Net 의존 단계 스크립트는 원본 그대로 복사(경로만 미러 안).
- DTA 열화본 c1~c4(`make_copies_c.py`): 무작위 밝기장, 어두운 톤 압축(톤 곡선), 음영, 블러, 대비, 잡음; c3·c4는 마스크 없는 무작위 영역에 3×3 grey closing.
- 검증: `build_nb_h9.py`가 기존 72개 nb/h9 파일을 비트 단위로 재현, `c14_partners.py`가 기존 짝 dev/test(평이·DTA B)를 차 0으로 재현,
  `c14_blend.py`가 076 test CSV를 4.5e-13로 재현. 같은 방법의 기존 dev 기준 = **9.5462**(dev-combo 9.535와의 차는 저장 OOF 사용 여부).
- 메모리: 16GB에서 MPS U-Net 학습 동시 6개 → 스왑 13GB 고갈. 동시 2개로 제한.

## 4. 새 정보 가설 점검(CPU, 10-16 오후) — 모두 기각
| 가설 | 결과 |
|---|---|
| 잡음이 밝기 의존(포아송형)이면 잡음 질감이 상 단서 | 밝기 5분위별 잡음 SD 상대값 1.00±0.01: 순수 가우스 → 기각 |
| 12~16 잡음 대역은 다른 재료군(라벨 SD 22.3 vs 16.7, 강건 SD 21.9) | 기울기 다소 큼(n 68, 공선성) — 대역별 늘이기는 Public 7/7 실패 계열 → 추구 안 함 |
| 평균 절편 길이(MIL, 방향별) | 깨끗 잔차 상관 |r|<0.04, Ridge 9.01→10.43 악화 |
| 분할 없는 잡음 보정 다중 척도 대역 에너지(spec_het) | 열화 강건(자기상관 0.7~0.88)이나 깨끗 타당도 0.25~0.39 |
| 결정립별 어두움 분포(gdark) | gd_f10 상관 0.66(최강 단일)이나 잔차 상관 0.02, Ridge 무효 |
| 정확한 '생성기 수준' 16량(마스크) | Ridge 9.81 < 운영 98열 8.71 → 단순 공식 아님 |
| 블록 단위 누적량 상분율 이질성(local_cumul) | 잡음 행 dMSE +5.3(ridge)/+10.3(log) 악화 |
- 확인된 사실: 깨끗한 행에서 소N(조대) 영상의 기울기 희석 없음 + 라벨 분산이 큼 → 라벨은 '실현된 구조' 함수. 깨끗 오차 8.0은 라벨 잡음(≈4.3)보다 훨씬 큼.

## 5. v1(무작위 밝기장) 준수 U-Net의 결과 — 잡음 행 측정 손실 → v2(톤 곡선 LUT)
- 특징 비교: U-Net 무관 76열은 비트 동일, U-Net 유래 22열은 기존과 상관 0.95~1.00(잡음 het4_u 0.96).
- TabPFN 같은 시드는 CPU·MPS 결과 동일(기존 특징 8.025 vs 8.024) → 차이는 특징 탓.
- 039 슬롯 4변형 평균 dev: 깨끗 8.038→8.075(dMSE +0.6±1.5), 중간 9.19→9.30(+2.2±4.2), **잡음(full) 12.67→13.08(+10.6±4.0)**.
  선형 짝도 중간 대역 nb +0.11~+0.26 악화. → 결정립별 밝기 오프셋 증강이 실제 잡음 영상 강건성의 핵심이었다.
- v2(`push-1400v2/phase_unet*.py`): 마스크 없는 **무작위 톤 곡선**(밝기 LUT, 상관 5 gray, σ2 평활 영상에서 평가) + 약한 밝기장.
  깨끗한 결정립은 밝기가 거의 균일하므로 결정립마다 거의 일정한 다른 오프셋이 된다(검증: 결정립 간 SD 3.2 vs 결정립 내 1.3, 진폭 5).
  일반 밝기 변환(톤 곡선)이며 분석 결과를 쓰지 않는다. 미러 `R2/`(열화본 이미지·Cellpose 특징은 R과 공유), `orchestrate2.sh`로 자동 실행.

## 6. 사용자 직접 질의 답변(10-16 18:2x) → 재구축 중단
- 질의: train 원본을 유지한 채 영상 분석으로 고른 일부 영역의 (1) 밝기·대비 조정, (2) 경계 영역 픽셀을 같은 이미지 주변 픽셀값과 혼합·대체해 경계를 약화.
  답변: 두 방식 모두 허용. 그 이미지/특징, 원본 라벨 사용, 보조 모델 특징·예측의 최종 모델 사용도 허용. 금지: test pseudo-labeling, 별도의 새 합성 이미지 생성.
- 해당: U-Net 결정립별 오프셋(1), deg·deg2 결정립 산포(1), realdeg2 어두움 배율(1)·경계선 화소를 결정립 평균으로 대체(2), DTA 라벨 사용, U-Net 특징.

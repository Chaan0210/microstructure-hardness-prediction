# 결정립 경계·연결 학습: 작은 OOF 개선, 제출 권고 보류

**연결 관계를 직접 배우는 모델을 구현하고 중첩 검증했지만, 제출할 가치가 있다고 권할 만큼 안정적인 경도 개선은 얻지 못했다. 082를 유지하고076을 롤백으로 보존한다.** 평균 개선은 전체0.01316·고잡음0.03417RMSE다. 그러나 개선한 분할은1/5이고 구간에0이 포함된다. 도움이 된10개를 제외하면 악화된다. 경계 복원 성과와 경도 일반화 성과를 구별해야 한다.

연결 모델은 무학습 대조보다 나았지만, 국소 연결 학습·일반 경도 학습·원본 보조 마스크 요약 대비 우위를 입증하지 못했다. 특히 원본 마스크 요약 대비 개선량 차이는 **+0.00096**,95% 구간 **[-0.03160, +0.03244]**다. 일반 경도 학습의0.02344 개선도 구간이0을 포함하고 상위10개 제외 시 악화돼 제출 근거로 삼지 않았다. 대조군 중 가장 좋아 보이는 것을 사후 최종 후보로 바꾸지 않았다.

이전 실패와 중복되는지 코드부터 확인했다([AUDIT.md](AUDIT.md)). 기존 U-Net은 Cellpose 기반4개 화소 클래스를 예측했고, u1b는 경계 약화 학습 후3개 상분율 열을 교체했으나 고잡음12.31→12.62로 실패했다. K6 그래프는 이미 추출된 결정립 객체 특징에 한 번의 이웃 전달을 적용했고, H0/Betti/C2·지도 PCA·U-Net/DINO 토큰 방식은 주로 고정 표현을 읽었다. 직전 실험은 가린 영역의 평균 명암·대비·기울기를 복원했다. 이번에는 원시 영상에서 경계 지도와 인접 연결을 학습하고, **잘못된 연결 하나 때문에 서로 다른 영역이 합쳐지거나 같은 영역이 끊기는 오류**를 직접 손실로 삼았다. 서로 다른 영상의 경도가 비슷하다고 표현을 묶는 경도 이웃 손실도 쓰지 않았다.

모델은558372개 파라미터의 작은 화소 피라미드와16×16 위치의2개 전역 attention 층(폭96),128×128 경계 디코더,32×32 인접 연결 그래프다. 입력은256×256 원본을2×2 평균해128부터 처리하므로, 원래 화소 정보를 모두 보존하는 구조는 아니다. 그래프 간격8px도 아주 작은/가는 결정립을 표현하는 데 한계가 있다. 경계·국소 연결 BCE에64개 샘플 쌍의 maximin BCE를 더했다. 연결 점수는 가능한 경로들 중 최소 연결 점수가 가장 큰 경로의 값이다. [MALIS 원 논문](https://arxiv.org/abs/0911.5372)의 개념에 따른 직접 구현이며, 원 논문의 데이터·모델이나 전체 쌍 Rand 목적의 완전한 재현은 아니다.

목표는 기존 학습 원본의 Cellpose 기본/D4 마스크에서 만들었다.0 라벨은 다른 결정립이 아니라 미측정으로 처리하고, 사용 가능한 뷰의75% 이상이 동의하는 내부 화소 쌍만 감독했다. 경계의 영상 내 근거에 위치별 가중치를 줬지만, 이미지·클래스별 정규화 때문에 전체적으로 잘못된 한 이미지의 영향까지 제거하지는 못한다. 상·기공을 하나의 인스턴스로 나눈 마스크가 실제 결정립과 다를 수 있고, 같은 보조 모델의 여러 뷰는 같은 오류에 동의할 수 있다. **보조 마스크는 결정립 정답이 아니다.** 균형 BCE의 sigmoid는 보정된 물리 확률이 아니므로, 점수 엔트로피를 검증된 사후 불확실성으로 해석하지 않는다.

약한 목표를 맞추는 능력은 실제로 달라졌다. 고잡음 보류 원본의 연결 BCE는 국소 학습 **0.35793 → maximin 0.24666**, **31.09% 감소**다. 두 방법 차이95% 구간은 **[−0.12148,−0.10145]**다. 반면 경계 BCE는0.35241→0.35915, 인접 연결 BCE는0.21874→0.23122로 조금 나빠졌다. 목표 변경이 전역 연결을 개선하는 대신 국소 분류와 절충한 것이다. 이것은 실제 결정립을 더 정확하게 복원했다는 검증이 아니다.

고잡음124개에서 확실한 국소 연결 목표의 중앙값 비율은 **36.49%**다. 마스크 경계의 원본 영상 근거AUC 중앙값은 **0.680**,10백분위는 **0.361**다. 보류 뷰와의 높은 합의는 이 확실한 부분에 조건부인 값이다. TRAIN_000025/158 같은 예시에서 모델은 약한 마스크의 미측정 영역에도 촘촘한 경계망을 채운다. 이를 실제 경계의 복원으로 확인할 독립 주석은 없다. 시각 진단에서는 해당 원본을 제외해 학습한 모델을 사용했다.

신뢰도 선택 정책은 경도 결과를 보기 **전에**, 이미지별 가중치 한계를 발견하고 별도로 고정했다([QUALITY-PLAN.md](QUALITY-PLAN.md), [quality-code-lock.json](quality-code-lock.json)). 영상 근거AUC가 우연 수준0.5를 **초과**할 때만 지원되는 원본으로 정의했다. 임계값 검색은 하지 않았다. 고잡음124개 중94개가 해당했다. 각 B 원본을 제외해 기존082 계수와 새 β를 둘 다 다시 적합하고, 전 구간·지원 원본만·보정 없음 중 LOO 이득과1SE 규칙으로 선택했다. 연결 모델이 유일하게 활성화됐던 원래 fold1에서도 내부 LOO 평균 제곱오차 이득은5.67, 표준오차6.04였다. 지원 원본으로 제한하면3.05 대5.61로 더 약해졌다. 따라서 추가 정책은5개 분할 모두 보정 없음을 선택했고082와 정확히 같았다. 원래 정책의 기존 기준, 두 정책에 대한 더 엄격한97.5% 구간과 고정된 최종 우선순위 모두 통과하지 못했다. 검증 후에 문턱이나 혼합 계수를 바꾸지 않았다.

새 특징을 넣은 단독 물리 Tab 판독기는 전체 **9.77662→10.08993**, 고잡음 **12.41766→12.77798**로 악화됐다. 따라서 강한082 위의 작은 보정 이득을 새로운 물리 측정의 전반적 정확도 향상으로 볼 수 없다. 단순 퍼짐만의 효과는 아니다. 고잡음 보정의 선형 위치·퍼짐 성분만 적용한 사후 진단 이득은 **+0.00257**, 이를 제외한 성분은 **+0.03160**다. 두 성분은 새 후보나 추가 적합이 아니다.

새 분기의 학습 크기를 A213으로 유지해 B와 V를 예측한 진단도 **+0.01242**,95% 구간 **[-0.02799, +0.06147]**였다. T320 재학습 크기 변화만으로 이득 부족을 설명하지 못한다. 또한 같은 원본을 동일320개 학습 크기의 모델에 포함/제외했을 때의 구조 통계를 비교했다. 연결 점수 엔트로피의 고잡음 평균 차이는 **+0.000049**,95% 구간 **[-0.00150, +0.00153]**로, 큰 평균 신뢰도 이동은 확인되지 않았다. 서로 다른 겹친 분할과 시드의 영향도 포함한 진단이며 한 원인의 부재를 증명하지는 않는다. PCA16은 학습된 잠재표현 분산 평균97.49%를 유지했지만, 이것이 경도 관련 정보의 보존을 보증하지도 않는다.

수치 재현성에서도 실제 구현 문제를 찾았다. 저장된60개 학습 모델·20개 무학습 모델의 대표 배치 특징 재추론은 전부 최대 차이0이었다. 하지만 같은 시드로 처음부터 다시 학습한 원래 maximin 모델은 달랐고, 일반 경도 모델은 정확히 재현됐다. 무학습 특징 계산까지 시작 순서를 맞추고 원래 영상을 그대로 써도 maximin 재학습 차이는 남았다. 따라서 처음의 차이를 보류 영상 변경이나 시작 순서 탓으로 단정하지 않았다.

실제 첫31개 학습 원본의 고정 logits·쌍·목표로 역전파만40번 반복했을 때, 중복 인덱스 gather 경사는 **40개의 서로 다른 해시**를 냈다. 최대 차이는 **1.16e-10**였다. 샘플 쌍의32.7%가 이미 다른 쌍이 선택한 연결을 재사용했다. 이런 작은 오차가 불연속적인 maximin 경로 선택을 거치면 재학습 경로 차이로 커질 수 있다. 실제 전체 재학습에서 가중치 최대 차이는0.0144~0.0160, 구조 서명 최대 차이는0.504까지 관측했다. 이 값은 **HV 예측 오차가 아니라 가중치·특징 단위의 차이**다.

같은 수학적 BCE를 연결별 양·음 가중치로 먼저 합산하는 [수정 손실](deterministic_loss.py)을 별도로 구현했다. 실제 배치에서는 독립float64 기준과 손실 오차7.04×10⁻⁸ 이하·경사 오차2.29×10⁻¹⁰ 이하였고,40회 반복 경사는 모두 같았다. 별도 수치 스트레스 사례의 경사 기준 차이는2.29×10⁻⁹ 이하로, 이 사례에서도 반복 경사는 같았다. 수정판을 같은 A213·40epoch·시드로 별도 프로세스에서 두 번 학습하되 두 번째 실행의 보류 warm-up 영상187개를 바꿨을 때, **가중치·학습/보류 특징 차이가 모두0**이었다([deterministic-replay/poison/verification.json](deterministic-replay/poison/verification.json)). 이는 중복 경사 집계가 재현성 문제의 한 원인이었음을 뒷받침하며 이 사례의 수정 효과를 확인한다.

**수정판으로 전체60모델 중첩 검증을 다시 수행하지 않았다.** 따라서 위 RMSE는 원래 고정된 모델들의 결과이고, 수정판의 성능으로 옮겨 쓰지 않는다. 원래 모델·예측·실패 재현 기록도 그대로 남겼다. 수정은 수치 재현성 개선이며 경도 RMSE 개선을 보장하지 않는다. 이 구분 때문에 새 제출 후보나 공식 최고 모델을 만들지 않았다.

검증은 A213/B107 안쪽 선택과 T320/V80 바깥 평가,5개 분할·2개 시드로 수행했다. 원본과 모든 D4 뷰는 함께 분할했다. 정규화·새 인코더·잠재 표준화/PCA·회귀·β·추가 라우팅은 각 적절한 학습 부분 안에서만 적합했다. 물리100열과 물리100+구조28+PC16(총144열)은 같은 원본 수와 원래 경도 목표로 비교했다. 단독 이미지 모델로082를 교체하지 않고 두 판독기의 차이만 high-noise β로 추가했다. 무학습 대조와 일반 경도+D4 대조도 같은 backbone·초기값·원본 방문 수·40epoch(무학습 제외)·판독 절차를 사용했다. 목적별 벽시계/FLOPs가 같다는 뜻은 아니다.

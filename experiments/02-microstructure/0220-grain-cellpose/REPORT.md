# 220 — Cellpose-SAM 결정립 분할 기반 측정

**결론(v2 수정 검증 기준): 결정립 단위 측정 모델을 best021과 0.5 고정 비중으로 섞으면 재분할 3개 모두에서 개발 OOF가 0.55~0.61 개선된다(통합 12.815→12.240, 조건부 CI [0.156, 0.990]). 사전 등록한 4개 게이트를 모두 통과했다. 제출 후보는 023이다.**

## v2 수정 검증(사용자 전달 리뷰 반영, `plan-v2.json` → `validate_v2.py` → `validation-v2.json`)
리뷰 지적 3건과 추가 1건을 고쳤다. v1 수치(아래 "v1 결과")는 폐기하되 기록으로 남긴다.
1. **블렌딩 가중치 누출**: v1은 바깥 훈련 fold의 best021 OOF 조각(`p021[tr]`)으로 가중치를 골랐다. 그 예측을 만든 모델 일부는 바깥 검증 fold의 정답을 학습했다. v2는 가중치를 결과 확인 전에 **0.5로 고정**해 best021 예측으로 아무것도 적합하지 않는다. 그래서 best021 구성요소를 내부 cross-fit할 필요가 없다. 전제는 검증 fold의 best021 OOF가 정직하다는 것이다(`cnn-nested-204/R-outer-poison`의 바깥 정답 오염 불변 검증).
2. **변환 열 선택**: v1은 전체 특징의 최솟값을 보고 log 변환 열을 정했다(`z_q50`이 −0.0014라 제외됨). v2는 정의로 고정해 36개 전 열에 `log1p(clip(x,0))`를 쓴다.
3. **검증·최종 절차 불일치**: v1 검증은 fold별 가중치, 최종은 0.42였다. v2는 둘 다 0.5다.
4. (추가) **모델 계열 사후 선택**: v1은 바깥 OOF를 보고 KRR을 골랐다. v2는 바깥 훈련 fold 안에서 내부 4-fold CV로 {ridge, KRR, HGB} 중 하나를 고른다. 15개 fold 모두 KRR이 선택됐다. 최종은 500장 5-fold CV로 같은 규칙을 적용한다.

- 개선 상위 5개를 제외해도 +0.353이다. 개선 ID 244개, 악화 146개다. 결정립 모델과 best021의 오차 상관은 0.81~0.83이다.
- 가중치 민감도(기술 통계, 선택에는 쓰지 않음): 0.3/0.4/0.5/0.6 모두 세 분할에서 개선이다.
- 같은 400장을 반복 사용했으므로 독립 검증이 아니다. 특징 정의와 분할 설정은 라벨을 보기 전에 정했지만, 이 세션에서 앞서 잔차 진단에 라벨을 사용했다.

## 설치·출처
- 격리 venv(`.venv`): torch 2.14.0 / torchvision 0.29.0은 `pretrained-cnn-185/.venv`에서 APFS 복제했다. 새로 설치한 패키지는 cellpose 4.2.1.1 외 의존성 8개다(`provenance.json`).
- 가중치 `weights/cpsam`: 1,233,587,898 bytes, SHA256 `e1440429…c29a81`(HF x-linked-etag와 일치), 라이선스 BSD-3-Clause. 대회 규정의 허용 라이선스 범위이며 로컬에서 실행한다.
- 원래 프로젝트 `.venv`와 best021 파일은 변경하지 않았다.

## 분할
- 설정은 `flow_threshold=0.8`, `cellprob_threshold=-2`이다. 라벨을 보기 전에 smoke 이미지 3장(`smoke-settings.png`)으로 골랐다. 기본 설정은 흐린 이미지 커버리지가 40%에 그쳤고, TV 전처리는 기공만 남겼다.
- train 500장 분할에 19분이 걸렸다(MPS, 2.3초/장). 객체가 20개 미만인 분할 실패는 dev400 중 10장이며, 극저대비·고잡음 미세 결정립 이미지다(`failed-6.png`). 이런 이미지는 라벨과 무관한 규칙으로 best021 예측을 그대로 쓴다.

## 특징(`features.py`, 36개, 라벨 미사용)
- 객체별 면적, 장단축비, 배향, solidity, 내부 평균 밝기(1px 침식, σ1 평활)를 측정한다.
- 밝기 척도: z = (기지 수준 − 객체 밝기) / (기지 수준 − 픽셀 0.1 분위수). 아핀 밝기 변화에 불변이다. 기공은 z > 0.75이면서 둥글고 작은 객체, 2상은 0.3 < z인 결정립이다.
- 크기(Jeffries식 밀도 포함), 크기 불균일성(log 면적 표준편차, q90/q10, 4×4 타일 간 편차), 신장·정렬, 2상 분율·크기비, 기공, 화질 지표를 계산한다.
- 합성 보로노이 단위 검증에서 2상 분율과 기공 수가 복원됐다(기공이 2개 이상일 때). 기공이 1개뿐이면 2상 일부가 기공으로 잡히는 한계가 있다.

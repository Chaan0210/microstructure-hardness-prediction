- 대회 참고 PDF(Swift PDFKit로 추출): 결정립 크기·2상·기공·신장/정렬·크기 분포 균일성/공간 불균일성. 절대 방향과 정렬 정도는 구분하라는 문구. 절대 방향은 잔차와 무관(|ρ|≤0.13).
- train/test 근접 중복 없음(흐림 후 상관 최대 0.69). train/test 특징 분포 동일.

## 3. 중요: 잔차 선별 특징의 선택 편향
- 결정립 인접 그래프의 이웃 차수별 log면적 상관 mI1~3(`graph_feats.py`)을 넣으면 dev가 4개 변형 모두에서 −0.11~−0.17,
  4변형 앙상블 10.1408 → 9.9980, 하네스 10.186 → 10.062.
- 그러나 대조 실험: 무작위 N(0,1) 100열 중 038 dev 잔차와 상관이 큰 3열(|ρ| 0.20/0.13/0.13)을 넣으면 dev 9.9757(더 좋음!).
  잔차로 고르지 않은 mI1·mI3만 넣으면 10.2049(악화). dev에 없는 train 100장에서는 −0.016(SE 0.13).
- 결론: dev 잔차로 고른 특징은 dev(및 같은 400장을 쓰는 하네스)로 검증할 수 없다. TabPFN은 우연 상관 열을 강하게 활용한다.
  mI2는 분할-절반 재현에서도 다중비교 기준을 통과하지 못함 → 기각, 후보 039 생성 중단(파일 없음).
- 앞으로: 특징은 물리적 근거로 사전에 정한 블록 단위로 넣고, 같은 열 수의 무작위(선별 없는) 잡음 대조와 함께 비교한다.
  잔차 선별을 쓴다면 절반에서 고르고 나머지 절반 행의 dev 오차로만 판단한다. 최종 검증은 Public.

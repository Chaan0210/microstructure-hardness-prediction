# push-900 (2026-10-12~): 측정 잡음 줄이기 — 깨끗한 행 분할 TTA, 실제 잡음 프리셋에 맞춘 U-Net

## 1. 데이터 사용 원칙
- 쓰는 데이터는 제공된 train 500장(이미지·라벨)과 test 1000장(추론만)뿐이다. 절차적으로 새 미세구조를 그리지 않는다(게시판 문의 미답변 사안).
- U-Net 학습 입력은 깨끗한 train 이미지에 열화를 가한 것이다(031 이후 제출 모델과 같은 증강 방식). 정답은 그 이미지의 제로샷 분할이고, 경도 라벨은 쓰지 않는다.
- 열화 매개변수는 모두 우리 train 이미지 통계로 맞췄다(§3). 외부 레포(jinw00ch01)는 '잡음 이미지에서 경계선·2상 대비가 약해진다'는 가설의 출처일 뿐이다. 그 레포의 수치로 만든 첫 열화(realdeg.py)와 이를 쓴 r1 학습은 중단·삭제했다(가중치 미생성).

## 2. 라벨 없는 진단 (train만)
- 2상 결정립 내부 질감 없음: 내부 잔차 SD/백색잡음 = 0.976(2상) vs 0.955(기지), lag-1 상관 0.04 vs 0.02 (`texture_check.py`).
- 2상과 기지는 크기·형상·군집이 같다: Δlog면적 −0.002, ΔAR −0.04, 2상-2상 이웃 비율/무작위 기대 0.99 (`phase_shape_check.py`). → 2상 판별 단서는 밝기뿐.
- 잡음 이미지 경계선 깊이(경계 화소 dip/S): 깨끗 0.079, 실제 잡음 0.040, 경계선 유지 시뮬 0.068, 결정립 면별 50% 제거 시뮬 0.038 (`line_check.py`, 블러는 §3 보정값).
- 기존 U-Net의 실제 잡음 이미지 판독 치우침(깨끗 행 대비, 깨끗 SD 단위; `unet_diag.py`): z1 m_ph 분산비 0.64, m_la_mean +0.27, m_la_std −0.85, z_f50 −0.81(분산비 0.43). m1·m2·h1도 같은 양상.

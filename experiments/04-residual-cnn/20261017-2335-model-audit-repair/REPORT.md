# 모델 전체 재점검과 세 가지 수정 검증

**이번 점검에서도 082를 교체할 만큼 검증된 개선은 확보하지 못했다.** 미완료 교사 정합 검증을 완주하고, 로그 역변환과 첫 합성곱의 다운샘플링까지 구현해 비교했다. 새로운 제출·최종 파일 변경은 없으며 082/076을 보존했다.

| 방법 | 전체 400 RMSE | 고잡음 124 RMSE | 082 대비 개선량 |
|---|---:|---:|---:|
| 보존된 082 | 9.25674 | 11.50813 | — |
| 기존 CNN, 076 내부 계수 재선택 대조 | 9.16971 | 11.28115 | +0.08702 |
| 076 교사로 재학습 | 9.18485 | 11.32080 | +0.07189 |
| 로그 역변환 보정 | 9.26392 | 11.52674 | -0.00718 |
| 촘촘한 합성곱+간격4 선택 대조 | 9.17247 | 11.28838 | +0.08427 |
| 촘촘한 합성곱+4×4 평균 | 9.19580 | 11.34943 | +0.06094 |

양수 개선량은 RMSE 감소다. 이 표는 Public 점수가 아니라 같은 400개 재사용 개발 이미지의 조건부 중첩 평가다. 모든 500개 라벨은 과거 노출되었고, 기존 U-Net/Cellpose 표현과 과거 선택은 새로 중첩 재학습하지 않았다. 여러 분할이나 부트스트랩이 새 독립 확인을 만들어 주지 않는다.

## 무엇을 실제로 확인했나

학습 CSV와 이번에 사용한 캐시의 ID/라벨 정렬, 500개 원본의 중복 여부, 교사 30개 묶음의 학습/질의 분리와 라벨 해시, 실패행 대체 규칙, 정규화·추론·앙상블 조립을 추적했다. 이미지 해시는 500개 모두 달랐다. 새 코드의 외부 라벨 사용 오류나 기본 라벨 순서 오류는 발견하지 못했다. 코드와 근거 위치는 AUDIT.md에 있다.

**교사 불일치는 존재하지만, 수정만으로 성능이 좋아지지 않았다.** 082의 CNN은 G021을 제외한 073 분기를 0.84로 정규화한 교사의 잔차를 배운다. 기존 T076 실험에서 완료된 교사 27개와 부분 계산 36개를 확인하고, 부족한 TabPFN 계산 180개를 완성했다. 기존 8개 CNN을 재사용하고 12개를 추가 학습해 5fold/2seed 검증을 끝냈다. 여전히 G021을 제외한 교사이며, 142/213/320 등의 학습 크기 차이까지 제거한 실험은 아니다.

076 교사 재학습의 082 대비 평균 이득은0.07189지만 95% 구간은[-0.04931033644018257, 0.21697886535285832]다. 같은 076 내부 계수 선택을 적용한 **기존 CNN보다 0.01514 나빴다**. 기존 계수를 고정하면 재학습 RMSE는 9.27633로 악화했다. 이전 2fold의 일치 대조 이득+.02511은 나머지 3fold에서−.04243으로 뒤집혔다. 전체 이득이 큰 10개를 빼면 082보다 0.07327 나빠진다. 큰 평균 이득을 새로운 영상 신호로 해석할 수 없다.

**계수 선택은 작은 내부 표본에 민감하다.** 각 B에는 고잡음 24~41개만 있다. fold4는 기준 예측의 고잡음 RMS 1.2575 변화와 함께 선택이 global/0에서 분리/1로 바뀌었다. 내부 라벨 한 개을 제외하는 진단의 최대 계수 변화는1.00000였다. 선택 손실은 저잡음 보정까지 평가하지만 실제 적용은 고잡음에만 하는 불일치도 있으며, 실제 적용 기준으로 계산하면 3/5fold의 선택 강도가 바뀐다. 이 수정 방향은 기존 calibration_order/역할 검증에서도 이미 불안정했으므로, 이번의 새 승자로 재포장하지 않았다. 큰 grain-set 오차도 실패행 대체 후 실제로 전달되는 크기와 구분했다.

**로그 역변환 보정은 주 병목을 해결하지 못했다.** 원본 소스별 중첩 OOF로 추정한 배율은.9872~.9961이었다. 이 데이터에서는 단순한 일괄 과소예측 가정이 맞지 않았다. 새 보정은 전체 0.00718,고잡음 0.01861 악화했고, 같은 데이터의 상수 오프셋 대조보다도 나빴다. 학습 크기를 256개로 맞춘 저장 모델 진단도 개선량 -0.00697였다. 단순 퍼짐/평균 보정으로 새 신호를 얻지 못했다.

**첫 다운샘플링을 바꾼 학습도 검증했다.** 기존 7×7/stride4를 7×7/stride1로 촘촘히 계산한 뒤, 4간격 선택 또는 4×4 평균을 적용했다. 파라미터는 양쪽 68,788개이며 교사, 목표, 시드, 40epoch, 원본 D4는 동일하다. 변경한 것은 모델 내부의 집계 방식이다. 두 군 모두 같은 MPS 환경으로 총 40개 모델을 완료했다. CPU와 GPU의 학습 궤적 차이가 상쇄된다고 가정하지 않고, 같은 GPU의 대조군과 기존 CNN에 동일한 계수 선택을 적용한 대조군을 함께 봤다.

평균 풀링 군의 082 대비 이득은 +0.06094, 95% 구간은 [-0.05173292170105328, 0.19529988144234514], 세 가설을 고려한 98.33% 구간은 [-0.07555910140639566, 0.2259823297055829]다. 개선한 fold는 3/5, 상위 10개 제외 이득은 -0.08180다. 같은 촘촘한 계산의 선택 대조군 대비 이득은 -0.02333, 동일 계수 절차의 기존 CNN 대비 이득은 -0.02608다. 사전 채택 기준과 추가 귀속 검사를 통과하지 못했다. 개별 seed, 고정 계수, 모든 대조군, 큰 손해 ID는 dense-results.json과 dense-per-image.csv에 보존했다.

원래 CNN의 1px 격자 진단 차이는 0.066~0.080HV RMS, 최대 0.212HV였다. 이것만으로 큰 격자 불안정성이 입증된 것은 아니다. 4×4 평균은 집계와 유효 수용 영역, 위치도 함께 바꾸므로 어떤 물리 구조가 달라졌는지 분리해 입증하지 못했다. 공유 오차나 이번 실패를 정보의 복구 불가능성으로 해석하지 않는다.

평균 풀링 변경의 개별 사례는 사후 진단으로만 사용했으며 새 규칙이나 모델 선택에 사용하지 않았다.

과소예측과 과대예측 사례가 함께 있어 일괄 평균 오프셋으로 모든 실패를 설명할 수 없었다.

## 검증·보존·실행

- 새 이미지 학습은 A213/B107 선택과 T320/V80 평가로 분리했다. 회귀 전처리, alpha, 보정은 해당 학습 partition만 사용했고 파생 사본은 원본과 그룹화했다. 모델, seed, epoch를 외부 점수로 고르지 않았다.
- 원래 CNN의 20개 문맥은 저장 예측을 정확히 재현했다. 교사 정합 CNN의 한 40epoch 전체 재학습은 학습 밖 라벨과 픽셀을 바꿔도 가중치와 원래 질의 예측 차이가 0이었다.
- 새 평균 풀링 CNN의 40epoch 재학습은 가중치 최대 차이 0, 원래 질의 예측 최대 차이 0HV였다. 저장 모델 추론은 모든 40개 모델에서 검사했다. 재학습의 정확 일치 여부는 True이며 저장 가중치 재현과 구분한다.
- 로그 회귀 120개 저장 모델의 추론과 소스 제한 재적합, 독립 RMSE와 상위 기여 제외 계산을 확인했다. 조건부 부트스트랩은 모델 선택 역사나 공유 학습 집합의 의존성을 제거하지 않는다.
- 새 계산 합계는 약 55.15분으로 90분 한도 이내다. CPU/MPS 프로브의 보수적인 3000초 게이트와 총예산의 불일치를 정확도 평가 전에 수정한 기록도 보존했다. 설치, 유료 자원 사용, 제출은 없다.
- **보호 파일 154,570개와 Git HEAD, 기존 tracked diff는 그대로다. 076 캐시 조립과 082 저장 가중치 추론 CSV가 원본과 byte 단위로 일치했다.** 이는 전체 과거 학습의 재실행을 뜻하지 않는다. 보존 검증에서만 기존 배포 test 입력을 읽었고 새 학습이나 선정에는 사용하지 않았다.
